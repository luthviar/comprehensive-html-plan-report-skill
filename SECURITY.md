# Security policy

This repository is documentation and templates only. It must never contain passwords, API keys, tokens, private keys, service-account files, personal data, or private project evidence.

## Reporting a problem

Do not open a public issue with a secret or sensitive payload. Use GitHub’s private security reporting flow for this repository and include only the minimum safe reproduction. If a secret was accidentally committed, revoke or rotate it first, then report the commit without pasting the secret.

The validator and `.gitignore` are safety nets, not a replacement for human review.
